# 养鱼经济学（HaireXe-fish-economy）

> 给你养的那条鱼省点电费。
> QQ 的鱼、B 站的鱼，装完全都适用，一条命令，不用改你原来的插件。

---

## 一、它到底干了啥（一句话）

你的鱼每说一句话，DSH 都会把**整段聊天记录 + 全部工具说明书**重新发给模型一次。
这个插件做四件小事：

1. **少带工具**：以前每次都带 27 个工具的说明书，现在只带 4 个"目录"，用到哪个再把哪个叫醒。
2. **少带长内容**：工具打印出来的长东西（读文件、跑命令），进记忆之前先剪掉中间，只留头尾。
3. **记忆封顶**：聊天记录太长时，自动把最旧的那段压成一句摘要，最近几轮原样保留。
4. **消息路径**：养鱼插件每次投消息都捆着同一段固定说明（实测占入站字符 **67%**），
   插件在投递前把"之前已经发过的那段"压成一句话，第一次出现的不动。

就这四件事。不动你的人设、不动你的日记、不动你的记忆文件。

---

## 二、为什么值得装（真实数据）

拿 11 个跑过的养鱼会话、6469 次请求算的账：

| 事情 | 现在 | 装上之后 |
|---|---|---|
| 每次请求带的工具说明书 | 5.87K token（27 个） | 3.03K（4 个目录，少 48%） |
| 长输出（读日记、跑命令那种） | 原样进记忆，每轮都重发 | 超过 2500 字先剪短 |
| 记忆长度 | 一路涨，峰值 **66 万**，一次都没压过 | 超过 15 万就自动压一次 |
| 每条入站消息 | 67% 的字符是之前发过的重复段 | 重复段压成一句，第一次的原样保留 |
| **总消耗** | 100% | **约 55%–60%**（也就是省 40%–45%） |

最后一行的意思：**以前发 10 次消息烧掉的钱，以后大概发 17 次才花完。**

> 说明白点：40%–45% 是拿同一批历史请求"按封顶重算"出来的上限估算；
> 实际会低一些（压缩本身也要花一次摘要的钱），我们估计落在 **35%–45%**。
> 其中消息路径那一项单独算：约省 **40M token（2.2%）**，好处是不动任何已有的东西，纯赚。
> 装完跑两天，看 `summary.json` 里的数字最准，第五节教你怎么看。

## 三、装（两条命令，装完就能用）

### 第 1 步：拿到这个库

```powershell
git clone https://github.com/HaireXe-d/HaireXe-fish-economy.git
```

（不想用 git 也行：点页面上的 **Code → Download ZIP**，解压到随便一个目录，记住路径。）

### 第 2 步：装进 DSH，然后重启

```powershell
dsh plugin --profile <profile> add "<库的路径>"
```

`<profile>` 就是 `~/.dsh/profiles/` 下的文件夹名（桌面版一般是 `desktop`，网页版是 `web`）。
**不想猜就用图形界面**：DSH → 设置 → 插件 → **从本地安装**，选这个文件夹，它会自己装进当前 profile。

装完**重启一次 DSH** 就生效了——不用改任何配置：

- 插件自带默认值：工具闸门开（fs+shell 常开）、入口裁剪开、自动压缩开；
- 只作用于路径里带 `whale` 的会话，写代码的会话不受影响；
- 之后想改什么，去设置页「养鱼经济学」卡片点开关，**不用再碰配置文件**。

> 插件管理器里能看到「养鱼经济学」这一张卡（包名 `dsh-fish-economy`），就是装成功了。

### 需要改默认值时（可选）

默认值不够用才动配置。在 `~/.dsh/profiles/<profile>/cordis.patch.yml` 末尾加同 id 的一段，
比如让压缩更早触发：

```yaml
- id: fish-economy
  config:
    budget:
      compactAtTokens: 100000
```

保存后**要重启**（配置文件只在启动时读一次）。日常开关不用走这里。

> 懒人版：仓库里的 `configs/fish-work.yml` 和 `configs/fish-chat.yml` 是现成的，整段复制粘贴就行。

## 四、两条鱼，各自怎么配

两条鱼（QQ 那条、B 站那条）跑的是同一套东西，插件这边**不用区分**，你只要选一个"预设"。
两个预设都默认**只在养鱼的工作目录里生效**（路径里带 `whale`），同一个 profile 里写代码的会话
一个工具都不会被收走——宁可少省一点，也不要吓到别的会话。

### QQ 养鱼 / B 站养鱼（会读日记、写日记、跑命令的）

```yaml
config:
  fish:
    enabled: true
    preset: work      # fs + shell 常开，其它八组睡觉；只作用于 whale 工作目录
```

为什么不能全关：实测你那条鱼 6469 次请求里调了 **5367 次工具**（一次请求平均 0.83 次），
其中 65% 是跑命令、34% 是读写文件。把这两类关掉，它就会不停地"把工具叫醒"，反而更费。

### 只聊天、从不碰文件的（纯聊天鱼）

```yaml
config:
  fish:
    enabled: true
    preset: chat      # 工具全睡，只剩 4 个目录
```

### 如果你的养鱼目录不叫 whale

`scope` 是路径子串，看你的会话工作目录叫什么就填什么（比如 `fish`、`qq-bot`）：

```yaml
config:
  fish:
    enabled: true
    preset: work
  gate:
    scope: ['fish']
```

### 设置里的大开关（想关就关）

安装之后，**设置 → 养鱼经济学** 里会多出一张卡片：

- **两个开关**（点一下立刻生效，**不用重启、不用改配置**）：
  - 总开关：关掉 = 工具照常下发、不裁剪、不压缩，和没装一模一样；
  - 压缩会话：只控制“上下文超阈值自动压”，**关掉它就再也不会动你的历史**，其它两刀照常；
- 三个数字：现在每次请求多少 token、工具说明书从多少降到多少、自动压缩了几次；
- 一行小字：当前预设和作用范围（比如“只作用于 whale 目录”）。

开关状态存在 `~/.dsh/fish-economy/state.json`，插件每秒看一次，所以切完约 1 秒生效。
（如果卡片上“压缩会话”显示“配置里关着”，说明 profile 配置里 `budget.enabled: false`，
那个开关就不起作用——把它改回 true 再重启即可。）

### 消息路径（不用你做什么，装了就有）

养鱼插件每次把消息投进会话，都捆着同一段固定说明（"按以下专属通道流程做…"）。
插件在**投递之前**把"这个会话已经发过的那一段"压成一句话，第一份原样保留：

```
第一次：按以下专属通道流程做：1) 这是主人 → 直接回……（全文 3000 字）
第二次：按以下专属通道流程做：1) 这是主人 → 直接回……（后面 2940 字与上文相同，未变，不用重读）
```

- 实测：入站消息里 **67.5% 的字符**是之前发过的段落，复利算下来约省 **40M token（2.2%）**；
- 只在你 gate.scope 匹配的会话里生效（默认就是 whale），别人的会话一条都不动；
- 只动文本里的重复段，图片、文件、正文都原样保留；
- 任何异常都会**按原样投递**，不会把消息弄丢。

想调（一般不用）：`messages.keep`（保留开头多少字，默认 200）、`messages.minChars`（多长的段才压，默认 80）、
`messages.mode`（`short` 保留开头 / `full` 整段只留一句 / `off` 关掉）。

### 想更省一点（可选，加一条）

默认压缩后还会保留约 16% 的记忆。想让记忆压得更狠，把下面这段也加上：

```powershell
dsh --profile <profile> --patch "<库的路径>\extras\compaction-aggressive.yml"
```

加完之后记忆会稳定在 2 万～20 万之间（现在你是 27 万平均、66 万峰值）。

## 五、怎么确认它真的在干活

**方法一：在会话里问它**

> 输入：`调用 fish_report，看看省了多少`

它会回你一张小账单：工具省了多少、压了几次、缓存命中多少、大概省了多少钱。

**方法二：直接看文件**

打开 `C:\Users\<你>\.dsh\fish-economy\summary.json`，看这几个字段：

| 字段 | 意思 |
|---|---|
| `perRequest` | 现在平均每次请求带多少 token（以前是 27 万，看它掉没掉） |
| `compactions` | 自动压缩了几次（以前永远是 0） |
| `compactedTokens` | 一共压掉多少 token |
| `cacheHitRate` | 缓存命中率（掉了正常，会回来） |
| `moneySaved` | 估计省了多少钱 |

**方法三：看冷启动日志**

启动 DSH 时如果能看到 `[fish-economy] info: 已加载：闸门=开 瘦身=budget ops=关 预算=150K`，
说明四个开关都上了。

## 六、常见担心

**会不会把我的鱼弄傻？**
不会。它改的是"发出去的内容"，不改"鱼是谁"：人设、日记、记忆文件一个字节都不碰；
压缩也只压最旧的那段，最近几轮原样保留。

**会不会把工具弄坏？**
不会。工具都还在，只是先不出现在清单里；模型要用时说一声就会被叫醒（或者你说话时它自己判断）。

**会不会更费钱？**
有可能，但只在一种情况下：**一两次就聊完的短会话**。因为它要花一次"把工具叫醒"的代价，
短会话摊不平。长会话（你这边的鱼基本都是几千次请求）稳赚。

**不想要了怎么卸？**

```powershell
dsh plugin --profile <profile> remove dsh-fish-economy
```

卸完所有改动自动消失，配置文件不用回滚。
